# KISS Projects

This is where I practice programming fundamentals by rebuilding things to see how they work. Each project takes one concept and turns it into a small program I can run, change, and learn from.

## Go projects

- [Simple MapReduce](go-projects/simple-map-reduce/README.md) explores how workers split up a word count and combine their results.
- [Wordfinder](go-projects/wordfinder/README.md) builds a trie to explore how words can share prefixes.
